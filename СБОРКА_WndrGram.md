# Как собрать WndrGram для iOS

Понадобится Мак. Всё остальное делает скрипт `wndrgram-mac-build.sh`.

## 1. Что нужно заранее

- Мак на **Apple Silicon** (M1, M2, M3, M4…). Intel не подойдёт.
- **macOS 26** и **Xcode 26.2** из App Store. После установки один раз открой Xcode и дождись, пока он доустановит компоненты.
- Около **50 ГБ** свободного места и нормальный интернет: скачивается исходный код Telegram, WebRTC и прочее.
- Командные инструменты: в Терминале выполни `xcode-select --install` (если уже установлены, команда об этом сообщит).

## 2. Сборка

Положи папку проекта, например, на Рабочий стол. Открой **Терминал** и выполни по очереди:

```bash
cd ~/Desktop/Telegram-iOS-master
chmod +x wndrgram-mac-build.sh
```

### Вариант А — для iPhone (IPA-файл)

```bash
./wndrgram-mac-build.sh --device
```

Результат: `~/WndrGram-iOS/out/WndrGram-device.ipa`.

### Вариант Б — для симулятора на Маке

```bash
./wndrgram-mac-build.sh
```

Результат: `~/WndrGram-iOS/out/WndrGram-sim.ipa`. Как поставить его в симулятор, скрипт напишет в конце.

Первая сборка занимает **30–90 минут**, следующие проходят быстрее. Во время первого запуска скрипт может спросить пароль от Мака: он добавляет тестовый сертификат Telegram в связку ключей.

## 3. Установка на iPhone

1. Установи **Sideloadly** (https://sideloadly.io) на Мак или ПК.
2. Подключи iPhone кабелем и перетащи `WndrGram-device.ipa` в окно Sideloadly.
3. Введи свой Apple ID (подойдёт обычный бесплатный) и нажми **Start**.
4. На iPhone: **Настройки → Основные → VPN и управление устройством** → нажми на свой Apple ID → **Доверять**.
5. На iOS 16 и новее включи **Настройки → Конфиденциальность и безопасность → Режим разработчика** и перезагрузи телефон.

С бесплатным Apple ID приложение нужно переподписывать через Sideloadly раз в 7 дней: это ограничение Apple. Пуш-уведомления с такой подписью обычно не работают.

## 4. Где настройки WndrGram

- **Настройки → WndrGram**,
- или **10 быстрых нажатий на вкладку «Настройки»** внизу экрана.

Там: режим призрака, сохранение удалённых сообщений и правок, архив с Face ID, внешний вид (прозрачность удалённых, метки, скругления пузырей и аватарок), подтверждения при отправке, режим стримера, экспорт и импорт настроек.

## Если сборка упала

Скрипт собирает с `--continueOnError`, поэтому в конце выводятся **все** ошибки сразу. Скопируй вывод Терминала от первой строки с `error:` до конца и пришли тому, кто дал проект. После исправлений просто запусти ту же команду снова.

Частые причины:

- `xcode-select: error` — не выбран Xcode. Выполни `sudo xcode-select -s /Applications/Xcode.app`.
- Закончилось место на диске — освободи место и запусти скрипт ещё раз.
- Сеть оборвалась при клонировании — удали `~/WndrGram-iOS` и запусти скрипт заново.
